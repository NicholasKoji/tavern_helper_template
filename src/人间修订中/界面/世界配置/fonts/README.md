These WOFF2 files are web-only subsets used for the four theme names in the World Configurator.

| File | Source family | Source | License | Included text |
| --- | --- | --- | --- | --- |
| `theme-archive.woff2` | LXGW WenKai Lite Regular v1.522 | https://github.com/lxgw/LxgwWenKai-Lite/releases/tag/v1.522 | SIL OFL 1.1 | 官署卷宗 |
| `theme-astrolabe.woff2` | Ma Shan Zheng Regular | https://github.com/google/fonts/tree/main/ofl/mashanzheng | SIL OFL 1.1 | 命盘推演 |
| `theme-terminal.woff2` | Fusion Pixel Font 12px Monospaced zh_hans v2026.07.20 | https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.07.20 | SIL OFL 1.1 | 管理终端 |
| `theme-neon.woff2` | Smiley Sans Oblique v2.0.1 | https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1 | SIL OFL 1.1 | 霓虹夜城 |

The original license text for each source is included beside the subset. The subsets are embedded into the compiled HTML by webpack and are not used for body copy.
